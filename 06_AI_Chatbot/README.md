# Project 6: NexusChat AI Contextual Conversational Assistant

An interactive AI chatbot featuring full conversation state memory, customizable system personas, message metrics, and export tools built with Streamlit and Transformers.

---

## 📌 Features
- **Contextual Memory**: Remembers previous turns in the current session.
- **Customizable Personas**: Tech Lead Mentor, Creative Writer, Socratic Tutor, and Executive Consultant.
- **Session Analytics**: Live turn counting and word count estimations.
- **History Management**: Clear session memory or export complete chat transcript to JSON.
